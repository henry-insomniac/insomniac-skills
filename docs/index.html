npm first

Install once. Run anywhere npm runs.

The package exposes the system command init-agent-docs. It wraps the same Python standard-library implementation used by this repository. 

npx -p insomniac-skills init-agent-docs --help
npm install -g insomniac-skills
init-agent-docs --project-name my-project
npm install -D insomniac-skills
npx init-agent-docs --with-design --with-agent-ops

What it creates

A project memory layer that agents can actually follow.

AGENTS.md

One collaboration entrypoint.

Shared project goal, working principles, validation rules, and the reading map for every coding agent.

DESIGN.md

Design becomes a repo contract.

Tokens, components, layout rules, and UI boundaries are available before agents start changing screens.

.claude/

Long-term project context.

Architecture, tech stack, Git collaboration, skill authoring guidance, and bug-fix history stay in the repository.

docs/agents

Agent operations are explicit.

Issue tracker notes, triage labels, domain reading order, ADRs, and skill usage rules can be generated on demand.

Command reference

Every flag is visible before users touch a repo.

The initializer protects existing files by default. Preview with dry-run, overwrite only with force.

Agent layer

Facts, workflows, design, and skills stay separate.

The generated repo shape gives agents a stable reading path without mixing project truth, design policy, operational process, and optional automation.

Core skill catalog

Reusable workflows, installed only when requested.

No skill is copied by default. Use --with-skills core or a specific skill name to install into .agents/skills/.
