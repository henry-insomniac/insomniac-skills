Open-source Agent collaboration scaffold

Project context, design rules, and Agent workflows in one command.

Initialize AGENTS.md, DESIGN.md, .claude/, Agent operating docs, and optional local skills without inventing project facts.

一个 npm 命令，为开源项目生成 Agent 协作文档、设计系统入口、长期上下文和可复用 skills。

Use the CLI npm package 
npx -p insomniac-skills init-agent-docs \
  --project-name my-project \
  --description "Reusable Agent baseline" \
  --with-design \
  --with-agent-ops \
  --issue-tracker auto

What it creates

A practical baseline for agent-ready repositories.

Collaboration entrypoint

AGENTS.md gives every agent the same project goal, working principles, and documentation map.

Long-term context

.claude/ stores architecture, tech stack, Git rules, skill authoring guidance, and bug-fix history.

Design contract

DESIGN.md can be generated for UI work, with tokens, component guidance, and design boundaries.

Agent operations

docs/agents/ records issue tracker, triage labels, domain-doc reading order, and skill usage rules.

npm first

Install with npm, run with npx.

The published package exposes the system command init-agent-docs. The wrapper calls the same Python standard-library implementation used by the repo.

npm 包提供系统命令，内部仍调用 Python 脚本，因此机器需要安装 python3。

npx -p insomniac-skills init-agent-docs --help
npm install -g insomniac-skills
init-agent-docs --project-name my-project
npm install -D insomniac-skills
npx init-agent-docs --with-design

Command reference

Every CLI option, explicit and predictable.

Option Default Purpose

Agent layer

Separate facts, workflows, design, and reusable skills.

The scaffold keeps project truth in long-lived documents and keeps optional agent operations explicit. Existing files are protected by default.

Core skill catalog

Reusable local workflows, installed only when requested.

默认不安装任何 skill；使用 --with-skills core 才会写入目标项目。

agent-docs-bootstrap

Initialize or repair project-level Agent docs without inventing nonexistent architecture.

template-maintainer

Maintain scaffold templates and keep README, architecture docs, and CLI behavior aligned.

skill-author

Create, update, or review Agent Skills with clear triggers, workflow, validation, and safety boundaries.

bug-fix-recorder

Record bug symptoms, impact, root cause, fix, validation, and follow-up in .claude/bug-fix-log.md.

repo-onboarding

Produce a fact-based repository orientation from real files, entry points, tests, and known risks.

security-boundary-review

Review scripts, installers, skills, publishing, credentials, network calls, and unsafe writes.

release-packaging

Prepare installer layout, release artifacts, package contents, and post-install validation.

agent-handoff

Summarize completed or paused Agent work so another maintainer can continue cleanly.
