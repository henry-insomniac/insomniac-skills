# Agent 操作规则

本目录记录 Agent 在 `{{PROJECT_NAME}}` 中执行任务时需要遵守的操作规则。

## 文件说明

- `issue-tracker.md`：issue、PRD 和任务流转位置。
- `triage-labels.md`：issue triage 状态和项目真实 label 的映射。
- `domain.md`：长期上下文、领域语言和架构决策的读取规则。
- `skill-usage.md`：项目级 Agent skills 的组合使用建议。

## 维护规则

- 修改 issue 管理工具或流程时，同步更新 `issue-tracker.md`。
- 调整 label 命名时，同步更新 `triage-labels.md`。
- 调整长期上下文、ADR 或领域文档布局时，同步更新 `domain.md`。
- 新增项目级 skill 或协作流程时，同步更新 `skill-usage.md`。
