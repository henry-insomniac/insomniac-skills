Install

Run with npx.

One-time setup uses npx. Global install adds init-agent-docs. Requires python3. 

npx -p insomniac-skills init-agent-docs --help
npm install -g insomniac-skills
init-agent-docs --project-name my-project
npm install -D insomniac-skills
npx init-agent-docs --with-design --with-agent-ops

Structure

One file, one job.

AGENTS.md: start. DESIGN.md: UI. .claude: context. docs/agents: process. skills/core: optional.
