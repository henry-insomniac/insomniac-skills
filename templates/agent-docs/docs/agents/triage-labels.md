# Triage Labels

Agent 在处理 issue triage 时使用标准状态名，实际写入 issue tracker 的 label 以本文件为准。

| 标准状态 | 项目 label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由 Agent 接手 |
| `ready-for-human` | `ready-for-human` | 需要人类实现或决策 |
| `wontfix` | `wontfix` | 明确不处理 |

若项目已有不同 label 命名，只修改“项目 label”列，不要修改“标准状态”列。
